# ue_anim_research
Research on free and paid animation and no-suit mocap options for a fluid, Wukong-style UE5 combat kit (Unsoul).
- Open **UE_ANIM_AND_MOCAP_OPTIONS.md**. Start with the Executive shortlist, then section 4 (Suggested stack).
- The sections cover webcam mocap, packs by weapon/move type, directional hit/ragdoll, and licenses.
- Check each Fab listing's license before you ship. **Do not commit purchased or Mixamo animation files to a public repo.**
- Open-source / CC0 combat animations you can legally use: **OSS_COMBAT_ANIMATIONS_UE5.md**.
