# Ironclad Hexapod - rig and animation set

Blender 5.2 source for the hexapod's animations. Everything is generated by script, so edits go in the scripts.

| File | What |
|---|---|
| `build_hexapod_anims_v2.py` | builds all 46 actions (analytic leg IK on the real joint pivots, baked to FK). Run: `blender -b Ironclad_Hexapod_Anim.blend --python build_hexapod_anims_v2.py` (needs the v1 .blend, not in git) |
| `Ironclad_Hexapod_Anim_v2.blend` | result: rig + mesh + all actions |
| `export_glb_v2.py` -> `Ironclad_Hexapod_v2_Animated.glb` | mesh + skeleton + every action in one glTF; this is what Unreal imports (FBX gave mismatched bone frames) |
| `render_sheets_v2.py`, `previews_v2/` | contact sheets for each action |
| `README_v2.txt`, `anim_manifest_v2.json` | action list, lengths, speeds, root-motion flags |
