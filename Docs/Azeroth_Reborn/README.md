# Azeroth Reborn

Shared **project Bible** inside [Project-Chimera-](https://github.com/nickfucina87-coder/Project-Chimera-).

This folder is the single source of truth for **Azeroth Reborn** so Nick, his brother, and every Grok Bot stay out of each other’s lanes. Chimera gameplay/code docs live elsewhere under `Docs/`; do not mix them into this tree.

## How to use this Bible

1. Read `BIBLE.md` before any Azeroth Reborn work.
2. Claim or update your lane in `WORKSTREAMS.md` **before** you start (who, what, status).
3. Put lasting canon, systems, and decisions in `BIBLE.md` (or a linked subdoc under this folder).
4. Do **not** invent conflicting lore, systems, or ownership. If something is unclear, add a question under Open questions in `BIBLE.md` instead of guessing.
5. Other Grok Bots: edit via PR or the owner’s ask; never silently overwrite someone else’s active claim in `WORKSTREAMS.md`.
